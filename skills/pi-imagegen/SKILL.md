# Pi image generation

Pi の `pi_imagegen` ツールを使う。会話モデルが Claude でも切り替えず、
画像のプロンプト作成・結果の確認は現在の会話モデルが行う。
画像生成だけ Pi の `openai-codex` (ChatGPT) 認証と画像生成枠を使う。
API キー、Codex CLI、Python、追加 npm パッケージは不要。

## 実行

- `pi_imagegen` が見つからない場合は、dotfiles の `bin/setup-pi.sh` を
  Pi 外のシェルで実行して再起動するよう案内する。このスキルを symlink 越しに
  読んでいる場合、チェックアウトの位置は SKILL.md の**実体**から 2 階層上。
  `~/dotfiles` や別ホストの絶対パスを決め打ちしない。
- ChatGPT 未ログイン・認証失敗の場合は、そのホストの Pi で
  `/login openai-codex` を案内する。会話モデルは Claude のままでよい。
  トークンの読み出し・表示や他ホストからのコピーはしない。
- 新規生成は `prompt` と必要なら `output` を指定する。既定の保存先は
  作業ディレクトリの `output/imagegen/<uuid>.png`。
- 編集・参照付き生成は `referenceImages` にローカルファイルのパスを順に指定する
  (PNG/JPEG/WebP、各 20 MiB 以下、最大 5 枚)。入力画像は先に Pi の画像閲覧機能で確認する。
  プロンプトに画像 1、画像 2 の役割 (編集対象、構図、画風、挿入物など) を明記する。
  参照画像も OpenAI に送信される。
- `background: "transparent"` で透過を要求する。`quality` と `size` は通常 `auto`。
  `size` を指定するときは `1024x1024` のような形式にする。
- 複数の異なる画像は 1 枚ずつ呼ぶ。既存ファイルは上書きせず、新しい名前にする。
- 返った画像を確認し、被写体・文字・構図・維持条件を評価する。
  修正時は変更点を絞り、必要なら生成画像を次の `referenceImages` に渡す。
- 認証・利用枠・ネットワークの失敗で自動連続再試行しない。
  タイムアウトでも生成枠を消費している場合がある。API キー方式に勝手に切り替えない。
- 最後に保存先と使用したプロンプトを伝える。プロジェクトから参照する画像は
  プロジェクト内に保存する。

## プロンプト作成

依頼が具体的なら意図を保って整理し、曖昧なら構図・照明など仕上がりに必要な
範囲を補う。頼まれていない人物、ロゴ、文言、ブランドを増やさない。
不明点が生成を妨げなければ妥当な仮定で進める。

次から必要な項目だけを使う。項目を全部埋める必要はなく、英語への翻訳も必須ではない。

```text
用途: Web のヒーロー画像、キャラクター素材など
主な依頼: ユーザーの意図
入力画像: 画像 1 は編集対象、画像 2 は画風の参照など
被写体と背景: 見た目、場所、周囲の状況
画風・素材: 写真、イラスト、3D、質感
構図: 画角、配置、余白、視線
照明・色・雰囲気: 必要な指定
文字 (原文のまま): 正確な文字列。必要がなければ文字なし
維持条件: 編集で変えてはいけない顔、服、背景、位置など
変更点・避けるもの: 具体的な範囲
```

透過やサイズはプロンプトだけでなくツール引数にも渡す。
写真・イラストが目的なら SVG や HTML の代用品を返さない。
既存 SVG の小修正などコードで正確に扱える作業は、元の形式で編集する。

API の根拠と保守時の注意は [references/api.md](references/api.md) を参照する。
